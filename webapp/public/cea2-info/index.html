5. 评审规则（含 I3 独立性要求）

三段式评审流程

每个交付物遵循统一的评审流程：

Draft → Verification Review → Confirmation Review → Released ↓ ↓ Passed? Passed? Yes / No Yes / No 失败→回退 失败→回退
  • Verification Review：技术评审（FSE + 相关工程师）
  • Confirmation Review：管理确认（FSM 或 FSM+FSE），独立性要求按 ASIL 等级
  • 配套模板：Annex 15（Review template）+ Annex 16（Checklist）
  • 评审报告：Annex 04（Confirmation review report）
  • Confirmation Review 须在 Production Release 前完成
  • ASIL 等级取所有安全要求中的最高 ASIL

独立性等级定义（ISO 26262-2, Table 1）

等级含义
I0宜执行；如执行，须由非编写人执行
I1须由非编写人执行
I2须由独立于编写团队的人员执行（不同直接上级）
I3须由独立于编写部门的人员执行（管理、资源、发布权限均独立）
